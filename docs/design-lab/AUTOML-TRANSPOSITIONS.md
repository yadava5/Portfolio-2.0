## Borrow, transposed into working-paper grammar (for Ch-04 flagship + apparatus)

1. **Decimal phase numbers `1.0 INGEST … 7.0 DEPLOY`** → Fragment Mono clause
   numerals on the Ch-04 pipeline diagram; `02 / 07` counter → "Phase 2 of 7"
   folio-style running header.
2. **Bright-line / muted-line headline formula** ("Train models in parallel." /
   "The champion is chosen for you.") → Fraunces action line + Newsreader italic
   consequence line. Use for chapter openers (already matches plan 3.10 pairs).
3. **Pinned TOC w/ tick + progress rule** → sticky margin-note column with a
   hand-drawn ink caret beside the active phase + thin ruled line that fills.
4. **Gate-as-questionnaire** (question cards → generated plan → human approves)
   → ink-line diagram: three small hand-drawn form boxes → arrow → document
   sheet; clay ONLY on the decision points. Paraphrase: "four or five cards
   constrain the plan before training begins."
5. **Diorama caption convention** (`5.0 TRAIN — real training workspace`) →
   figure captions: `fig. 5.0 — training workspace, live capture` (keep the
   credibility word "real"/"live").
6. **Leaderboard + progress idioms** → hand-ruled table: rank numerals, mono F1
   scores, champion row underlined in clay (NOT violet glow); filled vs open
   ink circle = running/done (no pulsing dots).
7. **⌘K keycap hints** → single-stroke boxed keycap glyphs, sparingly.
8. **Deliberate divergences to cite**: their own grain.css says noise "reads as
   visual chatter on white" — argument for our clean paper; skip deblur/shimmer/
   conic traces/fake cursor/violet (banned).
